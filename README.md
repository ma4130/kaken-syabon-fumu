# シャボン玉 ふみふみ

床に投影して、ふわふわ浮かぶシャボン玉を足でふんで割るゲームです。小さな子ども向けで、何人でもいっしょに遊べます。

- **index.html … 映しっぱなし用**（公開URL: https://ma4130.github.io/kaken-syabon-fumu/ ）
  スタートも終わりもなく、いつ来てもすぐ遊べます。30こ割るごとに「ごほうびタイム」（8秒間、玉がいっぱい＋紙ふぶき）。
  40秒だれも割らないと「みんなで ○こ」は消えて 0 にもどります。しばらくだれも来ないと、玉のそばに「ふんでね」と足あとが出ます。
  画面が暗くならないようにし（Wake Lock）、前にカメラを使っていたら開いたときに自動でカメラを始めます。
- **game.html … 時間つきのゲーム版**（「ふんで スタート！」→ 60秒 → 結果）

### 映しっぱなしのコツ
- 音はブラウザのきまりで、開いたあと1回だけ画面をタッチ（またはキー）すると鳴ります。
  だれも触らずに音を出したいときは、Chrome を `--autoplay-policy=no-user-gesture-required --kiosk` をつけて起動します。
- カメラの許可は https（公開URL）なら一度許可すれば次からは聞かれません。

以下はゲーム版を含めた共通の説明です。

- 失敗なし・みんなで「なんこ割れたか」を数える協力型
- 玉は大きくてゆっくり。玉のふちをかすっても割れます
- にじいろの玉は小さい玉4つに分かれ、金色の玉は星が出ます
- 数字は上下の両側に出るので、床のまわりのどこからでも読めます
- 真ん中の「ふんで スタート！」をふむと始まり、時間が来ると結果 → 自動で最初にもどります

## 遊びかた

`index.html` をブラウザで開いて全画面（F キー）にし、プロジェクターで床に映します。

足の見つけかたは2つ：

1. **タッチ／床センサー**：マルチタッチ（何人でも同時）に対応。LiDAR などがマウス移動として届くときは、設定の「のせるだけ」をオンにします。
2. **カメラ**：設定（⚙ または S キー）→「カメラを使う」→「自動で位置合わせ」。画面に4つの白い点が順に出て、カメラの映像と画面の位置を合わせます。部屋は暗めがおすすめ。反応が鈍い／勝手に割れるときは「かんど」で調整します。

## せってい

あそぶ時間（30／60／90秒／ずっと）、玉の大きさ、玉の数、速さ、音。設定はブラウザに保存されます。

キー：S せってい ／ F 全画面 ／ R はじめにもどる ／ スペース スタート

## テスト

URL に `?test` をつけると `window.__fumu`（step(x,y) / motion(x,y,r) / tick(秒) / state / reset）が使えます。`?test&auto=play|party|idle` でその場面まで進みます（game.html は start と `auto=play|end`）。
