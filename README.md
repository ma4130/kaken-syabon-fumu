# シャボン玉 ふみふみ

床に投影して、ふわふわ浮かぶシャボン玉を足でふんで割るゲームです。小さな子ども向けで、何人でもいっしょに遊べます。

- 失敗なし・みんなで「なんこ割れたか」を数える協力型
- 玉は大きくてゆっくり。玉のふちをかすっても割れます
- にじいろの玉は小さい玉4つに分かれ、金色の玉は星が出ます
- 数字は上下の両側に出るので、床のまわりのどこからでも読めます
- 真ん中の「ふんで スタート！」をふむと始まり、時間が来ると結果 → 自動で最初にもどります

## 遊びかた

`index.html` をブラウザで開いて全画面（F キー）にし、プロジェクターで床に映します。

足の見つけかたは2つ：

1. **タッチ／床センサー**：マルチタッチ（何人でも同時）に対応。LiDAR などがマウス移動として届くときは、設定の「のせるだけ」をオンにします。
2. **カメラ**：設定（⚙ または S キー）→「カメラを使う」→「自動で位置合わせ」。画面に4つの白い点が順に出て、カメラの映像と画面の位置を合わせます。部屋は暗めがおすすめ。反応が鈍い／勝手に割れるときは「かんど」で調整します。

## せってい

あそぶ時間（30／60／90秒／ずっと）、玉の大きさ、玉の数、速さ、音。設定はブラウザに保存されます。

キー：S せってい ／ F 全画面 ／ R はじめにもどる ／ スペース スタート

## テスト

URL に `?test` をつけると `window.__fumu`（start / step(x,y) / motion(x,y,r) / tick(秒) / state）が使えます。
